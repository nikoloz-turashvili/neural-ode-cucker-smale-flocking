# Neural ODE for Cucker–Smale Flocking Dynamics

## Overview

This project explores the use of Neural Ordinary Differential Equations (Neural ODEs) to learn continuous-time dynamics in multi-agent flocking systems based on the Cucker–Smale model.

The model is trained on synthetic trajectories generated by the classical Cucker–Smale system. Its predicted trajectories are compared with the ground-truth dynamics to evaluate learning accuracy and generalization to new initial conditions.

## Objectives

- Generate synthetic flocking data using the Cucker–Smale model.
- Learn continuous-time dynamics using a neural network parameterization.
- Train the Neural ODE using trajectory-level mean squared error (MSE).
- Use Runge–Kutta 4 (RK4) for numerical integration.
- Evaluate predicted trajectories against ground-truth trajectories.
- Investigate generalization to previously unseen initial conditions.

## Methodology

The workflow consists of:

1. Generating synthetic trajectories from the Cucker–Smale model.
2. Preparing the data for Neural ODE training.
3. Defining a neural network to approximate the system's vector field.
4. Solving the learned dynamics using numerical integration.
5. Optimizing model parameters using trajectory-level MSE.
6. Evaluating predictions and visualizing trajectory comparisons.
